# Student Management System

## About the Project

Student Management System is a web-based project made for managing student records in one place.

I made this project as a BCA student to practice Flask, Python, MySQL, HTML and CSS. The main purpose of the project is to make basic student record management easier.

The system allows the user to add students, view student records, update information and delete records. It also shows some basic statistics on the dashboard.

## Features

- Add new student
- View all students
- Search students
- Edit student details
- Delete student records
- View total number of students
- Calculate average marks
- Calculate average attendance
- Show top performing student
- Show students according to department
- Show pass and fail information
- Show semester-wise student data
- Department performance table
- Simple dashboard with charts
